# EPQ_Save_Systems_Project
*Subject to change!*
Devran Karatas -- To what extent do save systems affect player psychology, risk-taking and enjoyment in game design?

This project aims to create a small game with 3 different types of save systems: unlimited manual saving, checkpoints, and no saving. The game will assign each player a random save system and then use analytics to determine how their play style changes. The assignment of save system will be random and blind, so this means we will likely get the analytics of both when the player plays normally, and the moment of realisation when the player realises the save system they have. The play-testers will be from online and/or local, e.g. around the school. The reason I have chosen this project is due to a fascination with game design and personal experience with noticing how I play games differently depending on the risk and size of consequence, and how others play games, e.g. streamers who play punishing games like Dark Souls.

By the end of this project, there will be: 
- A small game with different save systems and tracking of player analytics 
- A report that examines and explains the data, and links the data to save systems 
- A 10 minute presentation of the game and report
